# DELETE SEOUL · 원작 서사 명세

`/deleteseoul` 원작(방공호 B-7 → 부유 감시도시 → 검문소)의 유일한 서사 기준 문서.
대사 원문은 `src/explore/story.ts`, 상태 흐름은 `src/explore/ExploreClient.tsx`가 진짜다. 이 문서는 둘이 따라야 할 규칙만 적는다.
실험 브랜치(`/deleteseoul-lab`, PR #50)의 구조는 여기에 들이지 않는다.
정밀한 규칙은 이 문서에 두고, 인물의 대사는 겪은 것과 원하는 것만 말한다.

## 1. 세계 규칙

| 개념 | 뜻 | 게임 속 근거 |
|---|---|---|
| 등록 | 도시는 시민마다 이름(등록 정보)을 이미 갖고 있다. 거부해도 지워지지 않는다. | 표석 |
| 추적 | 등록된 이름이 지금 무엇을 하는지 확인하는 쿠키. | 쿠키 팝업, 검문소 |
| 정지 | 추적을 거부한 시민은 '활동 확인 불가'가 되고, 도시는 그 **등록된 이름**에 정지 처분을 건다. 존재가 사라지는 게 아니다. | 이산의 석상 |
| 열람(복원) | 도시 **밖**에서 온 방문자가 이산의 실제 소개·작업·글을 열면 바깥의 활동으로 확인되어 이산이 다시 움직인다. 머리 → 몸통 → 움직임. 순서 자유. 주민들은 몇 번을 열어도 달라지지 않았다. | 터미널 3대, `외부 접속 감지 n/3`, 관리인 |
| 임시 활동 | 이산이 움직이는 것은 방문자의 열람 덕분이다. 정지 처분 자체는 취소되지 않았다. | 검문소 상태 줄 |
| 연결 기록 | 이 브라우저에 남은 게임 기록(열람, 위치 백업, 결말, 접속 시각, 부탁)이 이 방문자와 복원된 이산을 잇는 고리다. | 꼬리말 삭제 목록 |
| 삭제 | 웹사이트 꼬리말의 `delete seoul`은 **이 기기의 DELETE SEOUL 기록만** 지운다. 웹사이트·작품·다른 데이터는 그대로다. 고리가 끊기므로 이산은 다시 멈춘다. | ForgetCity |
| 기억 | 방문자가 기억하는 문장(〈이름 없는 사랑〉의 마지막 줄)은 기기에 없다. 기록을 거치지 않고 사람이 사람을 알아보는 신호다. 암호나 주문이 아니다. | 문장 입력 |
| 식별 불가 | 기억으로 깨어난 둘은 어떤 추적 기록에도 묶여 있지 않다. 대자비는 보지 못하고, 카메라는 `식별 불가`, 검문소는 정지할 대상을 찾지 못한다. | 空 결말 |

거부와 삭제는 다르다. 거부는 도시 안에서 추적을 거절하는 일(이름은 남고 정지된다), 삭제는 도시 밖에서 이 기기의 연결 기록을 지우는 일(도시가 둘을 이을 고리가 없어진다)이다.

### 실무 질문
- 주민은 왜 깨우지 못했나: 주민은 도시 안의 사람이라, 그들이 열어도 바깥의 활동이 되지 않는다. 대사로는 "몇 번이고 열어 봤어. 달라지는 건 없었지."만 말한다.
- 신호 없는 방공호에서 기록을 보는 이유: 터미널은 주민들이 들고 내려온 오프라인 사본이다.
- 기록을 지우면 다시 정지되는 이유: 이산의 임시 활동은 이 기기에 남은 열람 기록에 기대고 있었다.
- 문장이 재등록 없이 이산을 깨우는 이유: 방문자가 터미널 없이 직접 알아본다. 새 기록은 생기지 않는다.
- 다시 지상에 올라도 추적되지 않는 이유: 배전실 문에서 백업을 만들지 않고, 대자비는 둘을 추적 기록으로 확인하지 못한다.
- 검문소가 식별할 수 없는 방문자: 일치하는 등록 정보가 없으니 정지할 대상도 없다. 성문의 레이저가 꺼진다.

## 2. 목적지
이산의 바람은 **구름 밑으로 내려가 보는 것**이다. 이름은 언제나 **하층행 승강장**(Descent platform)이다.
이유는 복원된 이산이 직접 말한다. 이 동네와 방공호는 원래 땅에 붙어 있다가 도시째 들어 올려졌다. 아래에 아직 사람이 산다는 말이 있고, 무전수는 구름 밑 주파수에서 오는 콧노래를 잡는다(무전수 대사와 같은 사실). 이산은 그게 사실인지 모른 채, 땅이 아직 있는지 자기 발로 확인하고 싶어 한다.
- 방공호: 방폭문 왼쪽 벽의 낡은 표지 `하층행 승강장 · 지상 출구 → 큰길 끝`
- 지상: 광장에서 큰길로 들어서는 자리의 표지판 `↑ 하층행 승강장 · 검문소 경유` (감시 기둥과 떨어진 자기 기둥)
- 검문소: 성문 현판 `하층행 승강장 · 등록 시민 전용`. 성문 너머 다리 오른쪽 난간이 끊긴 자리(z -151 ~ -155)에서 계단이 구름 속으로 내려간다.
- 아래가 안전하다거나 진짜라는 보장은 하지 않는다.

## 4. 꼬리말 조건
`sanlee-promise`는 **검문소에서 물러난 뒤 이산의 부탁을 마지막 줄(시 한 줄)까지 본 순간에만** 쓴다. 검문소 전의 시 대화는 쓰지 않는다. 그래서 꼬리말 버튼은 "같이 갈 수 없다"는 문제를 본 뒤에야 켜진다. 관리인은 삭제를 미리 말하지 않는다. 검문소의 `쿠키 설정`에 도시 밖 삭제 안내가 작게 있다.

## 5. 결말

### 수락 — 안전과 떨어짐
조건은 수락 전에 화면에 이미 나와 있다(대기열은 방문자에게만, 이산의 정지 처분은 그대로, 동행 통과 불가). 새 규칙은 없다.
1. 영구 등록. 2. 대기열 배정, 출발 미정, 줄에 서 주십시오. 3. 끊긴/돌아온 횟수. 4. 이산 "먼저 서 있어. 나는 여기서 볼게." 5. 뒤따르던 발소리가 들리지 않는다. → 정적 → 버튼.
- 대자비는 금빛으로 잠잠해지고 시점은 줄 사이 빈자리에 들어가 선다. 이산은 줄 밖 그 자리에 남는다.
- `sanlee-ending=accept`는 첫 줄에서 쓴다. 다음 입장은 줄 속에서 시작한다. 로그아웃 링크는 남는다.

### 거부 — 두 번째 정지 시민
거부 쿠키 → 두 이름 정지 → 백업 삭제 목록 → 방공호의 두 석상과 표석 → "누군가 두 사람 사이에 작은 등 하나를 놓고 갔다."(실제 등) → 정적 → 버튼.
진행(열람·만남·대화·결말·백업)은 초기화된다. `sanlee-promise`와 발견한 결말은 남고, `sanlee-forgotten`은 만들지 않는다.

### 空 — 다음 한 걸음
조건: 꼬리말 삭제(`sanlee-forgotten`) → 기록이 하나도 없는 상태로 정지 시민에게 문장 → 이산이 터미널 없이 깨어남 → 지상 → 검문소.
1. "일치하는 등록 정보가 없습니다." 2. "정지할 대상을 찾지 못했습니다." — 성문의 레이저가 꺼진다. 3. 이산 "……열렸네." 4. 둘이 성문을 지나 다리 옆 계단 앞까지 걷는다. 5. 이산 "여기부터는 나도 몰라."
- 5에서 자동 걷기를 끝내고, 다리 위에서 계단참까지 이어지는 좁은 구역(x 0.6~8.0, z -154.4~-151.6) 안에서 **평소 조작**을 돌려준다(PC: WASD·마우스, 휴대폰: 조이스틱). 이산은 계단참 끝에서 방문자를 돌아보며 기다린다. 화면 아래 안내는 `계단 쪽으로` 한 줄뿐이다.
- 방문자가 계단 쪽(+x)으로 실제로 2m 나아가면(x ≥ 4.4) 완료된다. 시점 회전, 옆걸음, 점프로는 완료되지 않는다. 그 순간 조작을 다시 거두고, 이산이 계단 쪽으로 돌아선다. 5.2초 정적 뒤에 작은 버튼(처음부터 / 로그아웃)이 나온다. 걸어 나가지 않아도 위쪽 로그아웃과 설정창은 늘 쓸 수 있다.
- 결말 카운터는 보이지 않는다. 이 결말은 어떤 기록도 남기지 않는다.

## 6. 필수 / 선택
- 필수: 정지 이유, 터미널, 하층행 승강장 바람, 검문소 상태 세 줄, 물러난 뒤 이산의 부탁.
- 선택: 검문소 전의 시 대화, 쿠키 설정의 삭제 안내, 〈이름 없는 사랑〉(글 터미널), 그 밖의 주민 대화.
- 업적식 알림("숨은 결말이 열렸습니다")은 없다.

## 7. 저장과 재시도

| 키 | 생기는 때 | 지우는 것 |
|---|---|---|
| `sanlee-visited` | 터미널 열람(空 경로 제외) | 거부, 처음부터, 꼬리말 |
| `sanlee-met`, `sanlee-san-talked` | 정지 시민·복원된 이산과 대화 | 거부, 처음부터, 꼬리말, 문장 성공 시 met |
| `sanlee-backup` | 배전실 문 통과, 엄폐 성공, 사망·복원 | 거부, 처음부터, 꼬리말, 空 시작 |
| `sanlee-promise` | 검문소 뒤 이산의 부탁 마지막 줄 | 꼬리말 |
| `sanlee-ending`, `sanlee-endings-found` | 수락 첫 줄 / 수락 마지막 정적 | 처음부터(ending), 꼬리말 |
| `sanlee-last-login` | 입장 | 꼬리말 |
| `sanlee-forgotten` | 꼬리말 삭제 | 空 결말 시작 |
| 空 상태, 검문소 물러남·부탁·시 들음 | 이번 방문 동안 메모리에만 | 새로고침, 처음부터 |

음악: 결말 곡(空)은 결과 버튼이 나오는 순간부터 나온다. 그 전에는 지상에서 듣던 곡을 잇고, 방공호로 넘어간 거부 결말은 조용하다.
空 결말의 마지막 걸음 동안은 결말 글이 터치를 가로막지 않는다(조이스틱·화면 끌기 가능).

장면용 전역 상태(`autoWalk`, `walkArea`, `sanHold`, `gaze.gateOpen`)는 처음부터 다시와 페이지를 떠날 때 비운다.
언어·효과음·화면 설정과 탭 단위의 대자비 소개 표시는 도시의 인식 기록이 아니라서 남는다.
