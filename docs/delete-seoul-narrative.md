# DELETE SEOUL · 원작 서사 명세

`/deleteseoul` 원작(방공호 B-7 → 부유 감시도시 → 검문소)의 유일한 서사 기준 문서.
대사 원문은 `src/explore/story.ts`, 상태 흐름은 `src/explore/ExploreClient.tsx`가 진짜다. 이 문서는 둘이 따라야 할 규칙만 적는다.
실험 브랜치(`/deleteseoul-lab`, PR #50)의 구조는 여기에 들이지 않는다.

## 1. 세계 규칙

| 개념 | 뜻 | 게임 속 근거 |
|---|---|---|
| 등록 | 도시는 시민마다 이름(등록 정보)을 이미 갖고 있다. 거부해도 지워지지 않는다. | 표석, 이산 첫 대사 |
| 추적 | 등록된 이름이 지금 무엇을 하는지 확인하는 쿠키. | 쿠키 팝업, 검문소 |
| 정지 | 추적을 거부한 시민은 '활동 확인 불가'가 되고, 도시는 그 **등록된 이름**을 멈춘다. 존재가 사라지는 게 아니다. | 이산의 석상 |
| 열람(복원) | 도시 **밖**에서 온 방문자가 이산의 실제 소개·작업·글을 열면, 그것이 바깥의 활동 확인이 되어 이산이 다시 움직인다. 머리 → 몸통 → 움직임. 순서 자유. | 터미널 3대 |
| 동행 | 복원된 이산은 이 방문자의 열람 덕분에 '임시 활동' 상태다. 그래서 방문자 곁에서만 움직일 수 있고, 검문소는 이산을 방문자의 동행인으로 다룬다. | 검문소 동행인 줄 |
| 연결 기록 | 이 브라우저에 남은 게임 기록(열람한 터미널, 위치 백업, 결말, 접속 시각, 약속)이 이 방문자와 복원된 이산을 잇는 고리다. | 꼬리말 삭제 목록 |
| 삭제 | 웹사이트 꼬리말의 `delete seoul`은 **이 기기의 DELETE SEOUL 기록만** 지운다. 웹사이트, 작품, 다른 시민, 다른 브라우저 데이터는 그대로다. 고리가 끊기므로 이산은 다시 정지 상태로 돌아간다. | ForgetCity |
| 기억 | 방문자가 기억하는 문장은 기기에 없다. 기록을 거치지 않고 사람이 사람을 알아보는 신호다. 관리자 암호나 주문이 아니다. | 〈이름 없는 사랑〉의 마지막 줄 |
| 식별 불가 | 기억으로 다시 깨어난 둘은 어떤 추적 기록에도 묶여 있지 않다. 대자비와 검문소는 둘을 누구라고 불러야 할지 모른다. 부를 수 없으니 정지시킬 수도 없다. | 空 결말 |

거부와 삭제는 다르다. 거부는 도시 안에서 추적을 거절하는 일이고(이름은 남고 정지된다), 삭제는 도시 밖에서 이 기기의 연결 기록을 지우는 일이다(도시가 둘을 이을 고리가 없어진다).

### 실무 질문에 대한 답
- **주민들은 왜 이산을 옮길 수만 있고 깨우진 못했나?** 주민은 도시 안의 사람이다. 그들이 기록을 열면 도시가 자기 장부를 본 것으로 끝난다. 바깥에서 온 눈이 필요하다(관리인 대사).
- **신호 없는 방공호에서 왜 기록을 볼 수 있나?** 터미널은 주민들이 함께 들고 내려온 오프라인 사본이다(터미널 상태 문구 `오프라인 사본`).
- **터미널을 열면 정확히 무엇이 바뀌나?** 바깥 방문자의 열람이 이산의 활동으로 확인된다. 기록 셋이 다 열리면 이산은 움직인다. 이 상태는 이 기기의 기록으로 남는다.
- **기록을 지우면 왜 다시 정지되나?** 이산의 복원은 이 기기에 남은 열람 기록에 기대고 있었다. 그 기록이 없어지면 도시가 보기에 이산은 다시 확인 불가다.
- **기억한 문장은 왜 재등록 없이 이산을 깨우나?** 터미널을 거치지 않고 방문자가 이산을 직접 알아보기 때문이다. 아무 기록도 새로 생기지 않는다.
- **왜 지상에 올라가도 다시 추적되지 않나?** 배전실 문을 나설 때 위치 백업을 만들지 않는다. 대자비는 둘을 추적 기록으로 확인하지 못해 시선이 닿지 않는다. 카메라는 사람 모양을 보지만 `식별 불가`라고만 표시한다.
- **검문소는 식별할 수 없는 방문자를 어떻게 처리하나?** 일치하는 등록 정보가 없으니 정지할 대상도 없다. 통과 기록은 '없음'으로 남는다.

## 2. 목적지

이산의 바람은 하나다. **구름 밑으로 내려가 보는 것.** 이름은 언제나 **하층행 승강장**(Descent platform).
- 방공호: 방폭문 옆 벽의 낡은 표지 `하층행 승강장 · 지상 출구 → 큰길 끝`. 도시가 뜨기 전부터 있던 표지다.
- 지상: 광장에서 큰길로 들어서는 기둥의 표지 `↑ 하층행 승강장 · 검문소 경유`.
- 검문소: 성문 현판 `하층행 승강장 · 등록 시민 전용`. 성문 너머 다리 오른쪽에 구름 속으로 내려가는 계단이 보인다.
- 아래가 안전하다거나 진짜라는 보장은 하지 않는다.

## 4. 결말

### 수락 — 안전과 떨어짐
1. 영구 등록. 대기열 배정, 출발 시각 미정.
2. 동행인 이산은 등록할 기기가 없어 대기열에 넣을 수 없다(시스템 줄).
3. 연결이 끊긴 횟수·다시 온 횟수(감정 장면보다 먼저).
4. 이산: "먼저 서 있어. 나는 여기서 볼게."
5. 마지막: 뒤따르던 발소리가 들리지 않는다.
- 대자비는 금빛으로 잠잠해지고, 시점은 줄 사이 빈자리로 걸어 들어가 가만히 선다(플레이 중 써 온 '줄 속 정지' 그대로).
- 이산은 줄 밖 그 자리에 남는다. 다음 입장은 줄 속에서 시작한다(`sanlee-ending=accept`). 로그아웃 링크는 남는다.

### 거부 — 두 번째 정지 시민
1. 거부 쿠키 1개 저장.
2. 대자비: 추적 거부, 동행인 포함, 두 이름을 정지.
3. 위치 백업이 지워지는 목록.
4. 방공호. 나란히 앉은 두 석상. 표석: 끝까지 '모두 거부'를 누른 두 번째 사람.
5. 두 석상 사이에 누군가 놓고 간 작은 등 하나(실제 3D 불빛). 이 줄로 끝, 설명 문단 없음.
- 진행 기록(열람·만남·대화·결말·백업)은 초기화된다. 약속(`sanlee-promise`)과 발견한 결말은 남는다. 거부는 삭제가 아니다.

### 空 — 다음 한 걸음
조건: 꼬리말에서 기록을 지움 → 다시 입장 → 기록이 하나도 없는 상태에서 정지 시민의 짧은 첫 대사 끝에 문장을 건넴 → 이산이 기억으로 깨어남(터미널 없이) → 지상 → 검문소.
1. 검문소: 일치하는 등록 정보 없음.
2. 정지할 대상 없음 · 통과 기록 없음(화면이 잠깐 굳는다).
3. 이산: "부를 이름이 없으니까, 멈춰 세울 수도 없는 거야."
4. 둘이 성문을 지나 다리 옆 하층행 승강장 계단 앞까지 걷는다. 이산이 한 걸음 앞에 서서 돌아본다.
5. 이산: "여기부터는 나도 몰라." → **플레이어가 한 걸음을 직접 내딛는다**(W/↑/Space/E 또는 버튼). 이산이 앞서 내려가 기다린다.
- 잠깐의 정적 뒤에야 작은 버튼(처음부터 / 로그아웃)이 나온다. 결말 카운터는 보이지 않는다. 이 결말은 어떤 기록도 남기지 않는다.

## 5. 필수 / 선택 정보
- 필수: 이산이 왜 멈췄는지, 터미널을 열면 깨어난다는 것, 이산이 하층행 승강장에 가고 싶다는 것, 검문소가 그 길에 있다는 것, 검문소의 대가(영구 등록·대기열·출발 미정 / 정지).
- 선택: 지상의 이산과의 약속, 관리인의 "도시 밖에서 지워" 단서, 꼬리말 버튼 설명, 〈이름 없는 사랑〉(글 터미널), 그 밖의 주민 대화.
- 숨은 경로 단서 셋: ① 이산의 약속(시의 마지막 줄) ② 관리인·검문소 쿠키 설정의 "도시 밖에서만 지울 수 있다" ③ 약속을 들은 기기의 꼬리말 `delete seoul`과 그 확인창. 업적식 알림은 없다.

## 6. 저장과 재시도

| 키 | 생기는 때 | 지우는 것 |
|---|---|---|
| `sanlee-visited` | 터미널 열람(空 경로 제외) | 거부 결말, 처음부터, 꼬리말 |
| `sanlee-met`, `sanlee-san-talked` | 정지 시민·복원된 이산과 대화 | 거부, 처음부터, 꼬리말, 문장 성공 시 met |
| `sanlee-backup` | 배전실 문 통과, 엄폐 성공, 사망·복원 | 거부, 처음부터, 꼬리말, 空 시작 |
| `sanlee-promise` | 지상 이산의 약속 줄이 화면에 뜸 | 꼬리말 |
| `sanlee-ending`, `sanlee-endings-found` | 수락 결말 마지막 | 처음부터(ending), 꼬리말 |
| `sanlee-last-login` | 입장 | 꼬리말 |
| `sanlee-forgotten` | 꼬리말 삭제 | 空 결말 시작 |
| 空 상태(`ghost`) | 문장 성공 | 저장하지 않음(새로고침하면 사라짐) |

언어·효과음·화면 설정과 탭 단위의 대자비 소개 표시는 도시의 인식 기록이 아니라서 남는다.
