# DELETE SEOUL · 원작 서사 명세

`/deleteseoul` 원작(방공호 B-7 → 부유 감시도시 → 남쪽 전망대 → 검문소)의 유일한 서사 기준 문서.
대사 원문은 `src/explore/story.ts`, 상태 흐름은 `src/explore/ExploreClient.tsx`가 진짜다. 이 문서는 둘이 따라야 할 규칙만 적는다.
실험 브랜치(`/deleteseoul-lab`, PR #50)의 구조(악한 창조자, 되풀이, 개발 기록 보관소 같은 것)는 여기에 들이지 않는다.
정밀한 규칙은 이 문서에 두고, 인물의 대사는 겪은 것과 원하는 것만 말한다.

## 0. 세 시점
- **2026년의 작가 이산**: 실제 웹사이트(소개·작업·글)의 주인. 방공호 터미널과 그림 캡션(`이산, 〈제목〉, 2026`)으로만 나온다.
- **2087년의 데이터 이산**: DELETE SEOUL이 세계의 전부인 인물. 그림을 "내가 그린 걸로 기억"하지만, 그린 사람은 2026년의 이산이다. 망원경에서 자기만의 경험(빛)을 처음 갖는다. "나도 나만의 경험을 하고 싶어."를 직접 말한다.
- **2026년의 방문자**: 게임과 실제 웹사이트를 오간다. 기기의 기록이 지워져도 들은 이야기를 기억할 수 있는 유일한 쪽이다.

## 1. 세계 규칙

| 개념 | 뜻 | 게임 속 근거 |
|---|---|---|
| 등록 | 도시는 시민마다 이름(등록 정보)을 이미 갖고 있다. 거부해도 지워지지 않는다. | 표석 |
| 추적 | 등록된 이름이 지금 무엇을 하는지 확인하는 쿠키. | 쿠키 팝업, 검문소 |
| 정지 | 추적을 거부한 시민은 '활동 확인 불가'가 되고, 도시는 그 **등록된 이름**에 정지 처분을 건다. | 이산의 석상 |
| 열람(복원) | 도시 **밖**에서 온 방문자가 이산의 실제 소개·작업·글을 열면 바깥의 활동으로 확인되어 이산이 다시 움직인다. 순서 자유. | 터미널 3대, `외부 열람 기록에 연결됨 n/3` |
| 임시 활동 | 이산이 움직이는 것은 방문자의 열람 덕분이다. 정지 처분 자체는 취소되지 않았다. | 검문소 상태 줄 |
| 연결 기록 | 이 브라우저에 남은 게임 기록(열람 순서, 망원경 이용, 위치 백업, 결말, 접속 시각, 부탁)이 방문자와 복원된 이산을 잇는 고리다. | 검문소 기록 줄, 꼬리말 삭제 목록 |
| 삭제 | 웹사이트 꼬리말의 `delete seoul`은 **이 기기의 DELETE SEOUL 기록만** 지운다. 웹사이트·작품은 그대로다. 고리가 끊기므로 이산은 다시 멈춘다. | ForgetCity |
| 함께한 기억 | 망원경에서 이산이 먼저 빛을 봤고 방문자는 못 봤다는 **들은 이야기**. 기기에는 없다. 암호도, 보장도 아니다. 본 것이 아니라 들은 것에 대한 증언이다. | 정지 시민에게 건네는 말 |
| 관측과 식별 | 도시는 몸(형체)을 언제나 관측한다. 그러나 정지·조준 같은 **표적 통제**는 그 몸을 지금 활동 중인 기록(등록 이름 + 이 기기의 연결 기록)에 이은 뒤에만 건다. 드론의 막대는 이 "잇기"의 진행이다. | 드론 HUD `활동 기록 대조 중`, `식별됨 · 활동 기록 연결` |
| 정지 장벽 | 성문의 레이저 장벽은 **식별된(기록에 이어진) 대상에게만** 정지 명령을 고정한다. 기록 없는 몸에는 고정할 대상이 없다. 문이 열리는 것이 아니다. | 성문 옆 표시 `정지 장벽 · 대상 고정`, 검문소 안내문·상태 넷째 줄, 대기 줄 표지 `정지 장벽: 식별된 기록` |
| 식별 불가 | 들은 이야기로 다시 일어난 이산과 기록 없는 방문자는 몸은 보이지만 이을 활동 기록이 없다. 드론은 `형체 감지 · 활동 기록 연결 불가`만 띄우고 따라오지 않으며, 대자비는 조준하지 못하고, 성문 표시는 `대상 조회 중 → 활동 기록 연결 불가 / 정지 명령 대상 없음`이 된다. | 空 경로 전체, 空 결말 |

거부와 삭제는 다르다. 거부는 도시 안에서 추적을 거절하는 일(이름은 남고 정지된다), 삭제는 도시 밖에서 이 기기의 연결 기록을 지우는 일이다.
시(〈이름 없는 사랑〉 등)는 글 터미널의 작품으로만 남는다. 진행·약속·암호·복구·결말 안내 어디에도 쓰지 않는다.

## 2. 진행 단계 (하나뿐인 기준)
`ExploreClient`의 `phase` 하나가 목표 문구·화살표·미니맵·검문소 접근·재시작 자리·이산의 길을 정한다. 3D 쪽은 `route.phase`로 같은 값을 읽는다.
통제선 천막은 단계와 따로 `route.open`(저장값 `open`, 空 경로는 이번 방문 메모리)을 따른다. 그림(Cordon)과 충돌(`walkBlock`)이 같은 값을 쓴다.

| phase | 조건 | 목표(화살표) | 큰길 통제선 | 검문소 |
|---|---|---|---|---|
| `restore` | 열람 < 3 | 정지 시민 → 터미널 n/3 | 닫힘 | 터미널 안내 |
| `talk` | 열람 3, 이산과 대화 전 | 이산에게 말 걸기 | 닫힘 | — |
| `scope` | 대화 후, 망원경 관측 전 | `망원경으로 아래 살펴보기`: 길 위에서는 다음 경유점, 전망대 안에서는 망원경 | 닫힘 | "망원경부터 보고 오기로 했잖아." |
| `decide` | 관측(`seen`) 뒤, 결정 전 | `이산에게 대답하기`(이산) | 닫힘 | "여기서 더 갈지, 아직 대답 안 했잖아." |
| `descent` | `승강장으로 가자`(`agreed`) 또는 空 경로 | 천막 전: `이산과 통제선 끝 천막으로` → 걷힌 뒤: `하층행 승강장 · 검문소 경유` | 이산이 천막 앞에 서서 걷을 때 열림 | 선택지 |

- 골목(띠 A)에서는 화살표를 감추고 분필 화살표가 골목 입구까지 안내한다. 바깥 산책로·전망대(도시 판 밖)에서는 허공 너머를 곧장 가리키지 않고 다음 경유점을 가리킨다.
- 망원경 장면 도중과 들여다보는 동안은 화살표를 감춘다. 눈을 뗀 뒤 대화를 닫았다면 이산을 가리킨다.
- 하층행 표지(방공호 벽, 광장 표지판)는 처음부터 보이지만, 목표가 되는 것은 이산의 결정 뒤다.
- 통제선은 시간이나 대화 종료로 열리지 않는다. `승강장으로 가자`를 고른 뒤 이산이 돌아오는 길(BACK)을 실제로 걸어 천막 앞 자리에 닿고, 1.3초 뒤 천막을 걷는다("열렸네. 지나가자."). 그 뒤 틈 안쪽에서 기다렸다가 따라온다.

### 길과 경유점 (`zones.LOOKOUT_PATH`)
골목 입구(-37.3, 12.2) → 광장 북쪽 hold(-44, 17.2) → [드론 길 A] → 배송 대기소 처마 hold(-52.6, 29.6) → 서쪽 성문 → 산책로 hold(-66.6, 35.2) → [드론 길 B] → 남서 모퉁이 hold(-66.6, 47.8) → 남쪽 다리 → 전망대 입구 hold(-32.6, 47.6) → 망원경(-30, 49.4).
골목 입구에서 망원경까지 실제로 걷는 길은 약 92m(배전실 문에서는 약 120m). 광장에서 길 A를 피해 동쪽으로 길게 돌아가는 길도 막혀 있지 않다(드론 판정에는 영향 없음).
이산은 hold에서 기다리다 방문자가 다음 hold에 닿으면 경유점을 차례로 걷는다. 그 사이에 드론 길이 있으면 앞으로 2.6초 동안 그 길의 빛이 건너는 자리에 오지 않을 때만 건넌다. 이산은 드론에 들키지 않는다(호위 실패 없음).

## 4. 망원경 장면 (남쪽 전망대)
순서는 고정이고, 움직임은 모두 도착을 기다린다. 시간은 도착한 뒤의 멈춤에만 쓴다.
1. 이산이 전망대 입구 자리에 와 있을 때, 방문자가 전망대 안에서 이산이나 망원경에 말을 건다. 이산 "내가 먼저 봐도 돼?" 하고 접안렌즈 앞까지 걸어간다(이산이 아직 오는 중이면 "잠깐, 같이 보자. 금방 갈게.").
2. 이산이 접안렌즈 앞에 **도착한 뒤** 1.6초 정적 → "……! 저 아래, 뭔가 반짝였어." → 3.2초 뒤 이산이 옆으로 비켜서며 "여기. 한번 봐."
3. 망원경의 상호작용 이름이 `망원경 들여다보기`가 된다. 고르면 방문자가 눈 자리까지 두어 걸음 걸어가고, 도착하면 시야가 좁아진다(배율 0.42). PC는 마우스, 휴대폰은 화면 끌기로 정해진 범위(좌우 ±0.8, 위아래 -0.75~0.12) 안을 둘러본다. 구름 두 겹은 고개를 돌린 만큼 반대로 흐른다(가까운 겹이 더 많이). `눈 떼기` 버튼, E, Esc, 마우스 잠금 풀림, 설정창으로 나온다. 나오면 들여다보기 전의 자리와 방향으로 걸어서 돌아간다(순간이동 없음). 화면 낭독 문구는 "구름이 아래를 덮고 있다. 움직이는 건 구름뿐이다."뿐이다. **빛은 어느 화면·자막·낭독 문구·반복 방문·동작 줄이기 설정에서도 방문자에게 보이지 않는다.**
4. 눈 자리에 실제로 닿은 뒤 눈을 떼고 원래 자리로 돌아오면 관측이 끝난다(`seen`). 다가가는 도중에 그만두면 아무것도 바뀌지 않는다. 이산이 묻는다: "너도 봤어?" / (나) "아니. 난 못 봤어." / "……나만 봤구나." / "방공호에 있던 그림 있잖아." / "그걸 그린 건 2026년의 이산인데, 나는 내가 그렸다고 기억해." / "방금 그 빛은 내가 봤어." / **"나도 나만의 경험을 하고 싶어."** / "저게 뭐였는지, 내려가서 직접 보고 싶어."
5. 결정: "보고 돌아오자고 했는데." / "……조금 더 같이 가 줄래?" → `승강장으로 가자`(`agreed`, 이산 "고마워. 통제선 끝 천막 뒤에 틈이 있어. 내가 걷을게.") / `잠깐만`(이산 "응. 정하면 말해 줘.", 단계는 `decide`에 머문다).
- 대화를 닫는 것은 어떤 행동도 대신하지 않는다. 닫았다가 이산에게 다시 말을 걸면 그 줄부터. 결정 줄까지 들은 뒤로는 결정 두 줄만 다시 묻는다.
- 다른 구역으로 가면 끝나지 않은 장면은 처음으로(관측 전이면). 장면 뒤 다시 들여다보면 횟수만 늘고("구름이 다시 덮었네."), 진행은 바뀌지 않는다. 기억으로 깨어난 경로에서는 망원경이 글로만 나오고 기록을 남기지 않는다.

## 5. 위협 규칙: 드론과 대자비
| 자리 | 드론 | 대자비 |
|---|---|---|
| 줄 속 | **보인다**(빛 원 안이면) | 줄 위장이 통한다(가만히 서 있을 때) |
| 온전한 엄폐물 뒤 | 위협과 나 사이를 상자가 가리면 안 보인다(배송 대기소 처마, 큰길 엄폐물) | 같은 규칙(시선선을 엄폐물이 가림) |
| 트인 곳 | 빛 원(반지름 2.6m) 안이면 보인다 | 기존 시선선 |

- 드론은 레일을 따라 x로 오간다(`x = c + a·cosθ`). 광장 A(z 22.5, 바닥 원은 x -64~-20), 바깥 산책로 B(z 41.5, 산책로 폭만), 큰길 넷(z -36.5, -58, -84, -108: 엄폐물 사이 건너는 자리). 빛 원·빛기둥·가림·판정이 같은 위치, 같은 반지름, 같은 가림 상자를 쓴다. 바닥 원은 셰이더가 가림 상자를 직접 검사해 그림자 부분을 그리지 않는다(판정 높이 1.0m, 그림자 조명 없음).
- 빛에 들면 드론이 멈칫하고 레일 위에서 느리게(2.4m/s, 걷기보다 느림) 따라온다. 빛이 주황으로 바뀌고 위쪽에 흰빛·주황 막대가 찬다(약 1.4초). 빛 원 밖으로 앞뒤로 나가면 0.8초 뒤 놓치고 다시 훑는다.
- 광장·산책로에서 다 차면 `드론에 식별되었습니다` → 그 드론 길을 건너기 전 자리(가는 길: 광장 북쪽 또는 산책로 / 돌아오는 길: 모퉁이 또는 처마 밑)로. 이산도 그 자리로 옮겨 기다린다. 이미 지나친 만남과 망원경 장면은 되풀이하지 않는다. 배송 대기소 처마(지붕 상자)는 빛을 가린다. 사인파라서 줄마다 매 반주기 수 초의 건널 틈이 있다. 채우는 속도는 그대로(70/s).
- 큰길에서는 빛 속이면 줄 속이라도 대자비에게 보인다(`gaze.droneLit`). 다 차면 "식별됨 · 대자비에게 위치 전송" → 대자비가 곧장 조준(기존의 붉은 조준 신호·바닥 선). 죽음은 대자비의 레이저 하나뿐이다.
- 구별: 드론 = 차가운 흰빛(따라올 때 주황), 또렷한 테두리와 흐르는 주사선, 높고 짧은 전자음. 대자비 = 붉은 시선·화면 가장자리, 낮은 음. 예전의 흐릿한 장식 드론은 없앴다.
- 이산은 드론에 들키지 않는다(호위 실패 없음). §3의 경유점 규칙대로 건넌다.
- 空 경로: 빛은 여전히 몸에 닿고 HUD는 `형체 감지 · 활동 기록 연결 불가`를 띄운다. 따라오지도, 막대를 채우지도, 위치를 보내지도 않는다. 대자비도 조준하지 못한다(§1 관측과 식별).

## 6. 검문소
- 기록 줄(이 기기의 실제 값만): `이산의 기록 열람 순서 · WRITING → ABOUT → WORKS · 3/3`(실제 연 순서), `남쪽 전망대 · 망원경 이용 n회`(횟수가 없고 완료만 있으면 `망원경 이용 확인`). 빛을 봤는지 참·거짓으로 적지 않는다.
- 안내문은 대기열(등록 시민만)과 정지 장벽(활동 기록에 연결된 대상에게만 정지 명령 고정)을 나눠 적는다.
- 상태 네 줄: 방문자 대기열 배정·출발 미정 / 이산 기존 정지 처분·임시 활동 / 동행 통과 승인 안 됨 / 정지 장벽 — 연결된 기록 2건 · 정지 명령 대상 고정.
- 물러나기·다시 열기·로그아웃은 그대로.

## 7. 꼬리말 조건
`sanlee-promise = "2"`는 **검문소에서 물러난 뒤 이산의 부탁 마지막 줄("오늘 망원경에서 있었던 얘길 해 줘")이 뜬 순간에만** 쓴다. 꼬리말 버튼은 이 값일 때만 켜진다.
예전 값 `"1"`(시 한 줄 약속)은 게임에 들어올 때 지우고, 꼬리말도 켜지지 않는다. 그 방문자의 진행 기록(열람·대화)은 그대로라서 다음 할 일(망원경)이 늘 있다.

## 8. 결말
### 수락 — 안전과 떨어짐
조건은 수락 전에 화면에 이미 나와 있다. 1. 영구 등록. 시점이 큰길 가운데를 따라 걷기 시작한다(경유점 4개, 도착마다 다음 점). 2. 대기열 배정, 출발 미정. 줄 옆 마지막 경유점 앞에 닿아야 다음 줄. 3. 끊긴/돌아온 횟수. 빈자리에 들어서서 멈춰야 다음 줄. 4. 이산 "먼저 서 있어. 나는 여기서 볼게." 이산은 줄 밖, 그 자리가 보이는 곳에 선다. 5. 뒤따르던 발소리가 들리지 않는다. 다음 입장은 줄 속에서 시작한다.

### 거부 — 두 번째 정지 시민
거부 쿠키 → 두 이름 정지 → 백업 삭제 목록 → 방공호의 두 석상과 표석 → "누군가 두 사람 사이에 작은 등 하나를 놓고 갔다." 진행(열람·만남·대화·망원경·결말·백업)은 초기화되고, 부탁과 발견한 결말은 남는다. `sanlee-forgotten`은 만들지 않는다(거부는 삭제가 아니다).

### 空 — 다음 한 걸음
조건: 꼬리말 삭제 → 기록이 하나도 없는 상태로 정지 시민에게 들은 이야기를 건넴 → 곁에 머묾 → 이산이 터미널 없이 일어남 → 지상(이산이 통제선 끝 천막으로 가서 걷는다. 이번 방문만, 저장하지 않음. 망원경 장면 없음) → 검문소.
가는 동안 규칙이 먼저 보인다: 드론 `형체 감지 · 활동 기록 연결 불가`, 성문 옆 표시가 `대상 조회 중 · 형체 2 감지 · 활동 기록 대조 중`으로 장벽을 훑는다.
1. "[검문소] 방문자 조회 중… 활동 기록 연결 불가." 2. "[정지 장벽] 정지 명령 대상 없음." — 표시가 `활동 기록 연결 불가 / 정지 명령 대상 없음 · 장벽 대기`로 바뀌고 장벽 빛이 서서히 거둬진다. 문이 열리는 것이 아니라 고정할 대상이 없는 것이다. 3. 이산 "……지나갈 수 있겠어." 4. "성문 너머 다리 옆, 계단이 구름 속으로 내려간다." — 조작을 돌려받아 성문 홍예·다리·계단참(보이는 기단·난간과 같은 사각형)만 걸을 수 있다. 이산은 다리를 걸어 계단참에 먼저 선다. 둘 다 계단 앞에 닿아야 다음 줄. 5. 이산 "여기부터는 나도 몰라." → 평소 조작으로 계단참에 들어서서 1m 더 나아가야 끝난다(시점 회전만으로는 끝나지 않는다). 내디디면 이산이 계단 쪽으로 돌아서고, 정적 뒤 버튼.
- 3/3을 지어내지 않는다(HUD는 실제 0/3). 등록도, 기록도 남기지 않는다.

## 9. 저장과 재시도

| 키 | 생기는 때 | 지우는 것 |
|---|---|---|
| `sanlee-visited` | 터미널 열람(연 순서대로, 空 경로 제외) | 거부, 처음부터, 꼬리말 |
| `sanlee-met`, `sanlee-san-talked` | 정지 시민·복원된 이산과 대화 | 거부, 처음부터, 꼬리말, 증언으로 일어날 때 met |
| `sanlee-scope` | `{uses, seen, agreed, open}`: 들여다본 횟수 / 이산과 함께한 관측 끝 / 승강장으로 가기로 함 / 이산이 천막을 걷음. 예전 `{done:true}`는 셋 다 참으로 읽는다 | 거부, 처음부터, 백업 없는 사망, 꼬리말 |
| `sanlee-backup` | 배전실 문 통과, 엄폐 성공, 사망·복원 | 거부, 처음부터, 꼬리말, 空 시작 |
| `sanlee-promise` | `"2"`: 검문소 뒤 이산의 부탁 마지막 줄 | 꼬리말(`"1"`은 입장 때 지움) |
| `sanlee-ending`, `sanlee-endings-found` | 수락 첫 줄 / 수락 마지막 정적 | 처음부터(ending), 꼬리말 |
| `sanlee-last-login` | 입장 | 꼬리말 |
| `sanlee-forgotten` | 꼬리말 삭제(기록이 지워졌다는 작은 표시) | 空 결말 시작 |
| 空 상태와 空의 천막, R-07 친구, 검문소 물러남·부탁 들음, 망원경 장면 중간 줄·결정을 들었는지, 길 위의 만남, 이산의 경유점 | 이번 방문 메모리에만 | 새로고침, 처음부터 |

재시작 자리: 드론 식별 → 그 드론 길을 건너기 전 경유점 1.2m 앞(§5) / 큰길 실패 → 큰길 입구(기존).
정리: `autoWalk`(큐 포함), `walkArea.rects`, `walkBlock`, `sanHold`, `gaze.gateOpen/still/zoom/clamp/lookAt`, `route.phase/open`, 드론 추적·식별·형체 상태, 이산의 경유점, 길 위의 만남은 처음부터 다시·구역 이동·결말 정리·페이지를 떠날 때 비운다. 설정창을 열면 망원경에서 눈을 뗀다. 식별 연출 도중에 화면이 사라져도 멈춘 걸음을 풀어 둔다.
음악: 결말 곡(空)은 결과 버튼이 나오는 순간부터. 대자비 곡은 소개 팝업을 닫을 때부터.
