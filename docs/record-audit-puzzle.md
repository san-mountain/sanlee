# 퍼즐 B — 없었던 3초 (도장 기계 리디자인 v0.5)

## 핵심 플레이
A 완료와 동시에 이산 왼쪽의 **기록 수정 프레스**가 자동으로 움직인다.
거부(붉은 X)가 적힌 종이가 프레스로 들어오고, 기계는 그것을 '동의'(녹색 ✓)로 덮어쓴다.
플레이어는 글을 읽기 전에 기계의 반복 동작에서 조작을 발견한다.

**실제 입력은 단 두 번이다.**
1. 크게 움직이는 황동 레버를 직접 눌러 프레스를 멈춘다. 거부 기록을 덮는 도장이 위로 올라간다.
2. 앞쪽으로 튀어나온 원본 종이테이프를 직접 눌러 꺼낸다. 원본 내용: **14:02:01 — 모두 거부**.

그 뒤 B 기존의 이산 대사와 '보증인 등록이 필요합니다' C 예고로 이어진다.
새로운 이산 얼굴/상체 상태, 범종, 지상, 엔딩은 바꾸지 않는다.
공식 중앙 기록은 여전히 '동의'다.

## 상호작용
- **모바일:** 움직이는 레버/테이프를 실제 화면에서 직접 탭한다. 화면 조작 레이블 오버레이는 없다. 드래그는 시야 조작으로 남긴다. 기존 우측 행동 버튼은 보조 입력이다.
- **PC:** 가까이에서 레버/테이프를 바라보고 E 또는 클릭한다. 기존 하단 근접 프롬프트만 사용한다.
- **목표:** 현재 가능한 조작만 퀘스트 화살표가 가리킨다. 첫 목표: '도장을 멈추십시오', 이후 '드러난 원본 테이프를 꺼내십시오'.
- 추가 안내나 튜토리얼 화면은 만들지 않는다. 레버는 살아 있는 동안 은은하게 빛나고, 정지되면 원본 종이가 앞으로 나온다.
- 입력 가능 범위는 장치로부터 약 4.6m 이내. 중복 클릭이나 드래그 중 실수로 실행되지 않도록 한다.

## 데이터 호환
기존 `sanlee-record-audit-v1` 저장을 유지한다. 내부 저장 이름은 예전 시험 장치에서 유래했지만 상태가 의미하는 단계만 재해석한다.

- `played`: 프레스 작동을 확인/진행함
- `mismatch`: 프레스를 멈춰 원본을 노출함
- `taken`: 원본 증거를 확보함
- `done`: 이산 대사와 C 예고까지 끝냄

신규 A 완료 후 `restPhase`는 곧바로 `test`(기계 가동 상태)를 반환한다. 기존 B 도중 저장해도 이어갈 수 있으며, 구버전에서 이미 불일치 기록이 있다면 원본 테이프가 나온 상태부터 재개한다. 새 세이브에서는 수락/거부 시험을 거치지 않는다.
시민 활동 기록은 `audit.interrupt` 한 번으로 남으며, 범종이 보호 중이면 기록되지 않는다. **행동 기록과 퍼즐 진행 저장은 별개**다.

## 전환·서사
원본은 수정 도장이 내려찍히기 전의 실제 입력 흔적이다. 프레스를 멈춘 플레이어가 도장의 결과물 뒤에 남아 있던 거부 기록을 보존한다. 원본을 찾아도 중앙 서버의 과거 공식 기록은 수정되지 않는다.
이산은 `……내가 거부했었구나.`와 `그런데 난 왜 아직 여기 있는 거지?`를 말한다.
보증 장치만 켜지며 퍼즐 C는 구현하지 않는다.

## 검수
- A 새 경로 두 선택 모두 B 프레스 작동
- 원본을 꺼내기 전에는 완료 불가
- 모바일 레버/종이 3D 직접 탭, A 원통/선택 직접 탭
- 드래그/터치 오작동 없음
- 레버 중단 직후 새로고침, 종이 확보 직후 새로고침, 완료 후 새로고침
- 구버전 A/B 저장, legacy 지상 경로, 진행 삭제
- 테스트 및 빌드 후 실제 조작감은 사용자 직접 검수
