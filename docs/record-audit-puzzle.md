# 퍼즐 B — 없었던 3초

퍼즐 A(얼굴)를 끝낸 새 경로에서만 켜지는 기록 검증 장치. 이산의 받침대를 사이에 두고 얼굴 복원 장치와 마주 본다(`AUDIT_MACHINE`, 방 왼쪽).
무전수가 지상 검문소에서 떼어 온 도시 인증 단말기(검은 금속)를 나무 장 위에 얹고 놋쇠로 기운 모양이다.

## 흐름

1. 퍼즐 A가 끝나면 시제품 끝 카드 대신 장치에 불이 들어오고, 화면 아래에 "이산의 마지막 기록을 확인하십시오" 한 줄이 잠깐 뜬다. 퀘스트 화살표가 지금 켜진 부분 하나만 가리킨다.
2. 오른쪽 **기록 재생 손잡이** → 위 화면에 세 줄이 찍힌다: `14:02 — 추천 감정 구매 승인` / `시민 동의: 확인됨` / `입력 원본: 일부 누락 (3초)`(붉게 깜박임). 장치: "입력 원본 3초 누락. 입력 시험이 가능합니다."
3. 앞의 두 물리 버튼: 청록 **✓ 모두 수락**, 빨강 **✕ 모두 거부**. 가운데 두 표시창 **입력(INPUT)** / **처리 결과(OUTPUT)** 와 위의 표시등, 사이의 `=` 일치 / `≠` 불일치 표시.
   - 수락: 입력 ✓ 수락 · 결과 ✓ 수락 · `=` · 맑은 성공음 · 도시 "동의해 주셔서 감사합니다."
   - 거부: 입력 ✕ 거부 · 결과 ✓ 수락 · `≠ 불일치` 깜박임 · 어긋난 오류음 · 도시 "고객님의 선택을 존중합니다." → "모두 수락이 완료되었습니다." 표시등은 어긋난 채 남는다.
   - 순서 강제 없음. 거부부터 눌러도 된다.
4. 불일치 직후 왼쪽 옆면 **감사 기록함**: 경고등 깜박임 → 걸쇠 소리 → 덮개가 조금 들리고 기록지 끝이 보인다. 장치: "입력과 처리 결과 불일치. 감사 기록함 잠금 해제."
5. 기록함과 상호작용 → 기록지가 올라오고 2D 카드로 읽는다: **14:02:01 — 실제 입력: 모두 거부**, 중앙 서버와 분리된 보존 기록, "공식 기록: 여전히 '동의한 시민'". 여기서 퍼즐 해결(`taken`). 공식 기록은 바뀌지 않는다.
6. 기록지를 닫으면(버튼·E·Esc) 마무리: 도시 안내가 "…안전하게 보—"에서 끊기고 장치 화면이 식는다 → 카메라가 이산을 본다 → "……내가 거부했었구나." (침묵) "그런데 난 왜 아직 여기 있는 거지?" → 받침대 뒤 **보증 장치**에 불이 들어온다 → "보증인 등록이 필요합니다." → 시제품 끝 카드(퍼즐 B 끝).

퍼즐 C의 게임플레이는 없다. 보증 장치는 외형·표시등·짧은 안내뿐이다.

## 조작

- PC: 바라보고 E / 클릭. 두 버튼은 하나의 대상이며, 화면 가운데가 향한 쪽 버튼이 강조되고 안내 문구도 그 버튼 이름으로 바뀐다.
- 모바일: 손잡이·버튼·기록함을 직접 탭(보이는 것보다 넓은 투명 판정). 행동 버튼으로도 같은 동작.

## 저장 (`sanlee-record-audit-v1`, schema 1)

- `played`, `last {input, output}`, `tried`, `mismatch`, `taken`, `done`. 퍼즐 A 저장(`sanlee-face-auth-v1`)과 별개라 A의 선택·legacy 판정을 바꾸지 않는다.
- 새로고침: 기록만 봤으면 버튼 단계, 시험 도중이면 마지막 표시등 그대로, 불일치 뒤·기록지 확보 뒤(마무리 전)면 열린 기록함, 끝냈으면 보증 장치가 켜진 상태.
- legacy 저장에는 장치가 나타나지 않고 기존 지상 경로가 그대로다.
- 설정의 진행 초기화와 웹사이트의 도시 기록 삭제는 이 키도 지운다.

## 시민 활동 기록과 범종

- 버튼을 누를 때마다 `audit.test`(sourceId = 누른 입력)를 기존 `recordCitizenActivity`로 판정한다. 범종 보호 중이면 남지 않는다. 진행 저장은 보호와 무관하게 늘 남고, 소급 삭제는 없다. 기록지(아날로그)는 도시 기록 대상이 아니다.
- 범종은 B의 정답이 아니다.

## 대사 (story.ts)

- `auditLines`: ID `b.<화자>.<이름>`, 화자 `verifier`(기록 검증 장치) · `city` · `san` · `guarantor`(보증 장치), 한·영, 자막 시간. 장면 순서는 `auditScenes`, 화면 문구는 `auditUi`.
- 새 경로 NPC 대사는 진행별(`npcStages`: 관리인·무전수·스님). 관리인의 "터미널을 열면 깨어난다" 문구를 지웠다.
