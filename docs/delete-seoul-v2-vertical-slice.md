# DELETE SEOUL — 3D 리디자인 실험판 QA / v1.2

기준 브랜치: `feat/delete-seoul-rebuild-3d-v1` · 리뷰 PR #50 (Draft)

## 이번 리디자인의 고정 조건

- 전체 1인칭 **3D** 유지. 2D 전환 및 기존 A/B 퍼즐 완료는 필수가 아니다.
- 원본 포트폴리오 `/deleteseoul`과 원래 로컬 저장 키는 유지.
- 실험판 `/deleteseoul-lab`, 작품 바깥 삭제 화면 `/deleteseoul-lab/erase`.
- 지하 공간 임시 명칭: **잔상실 / Afterimage Archive**. 사원이 아니라 2026년 제작 자료와 사라진 관계·기억을 보관하는 재활용 지하 자료실. 3D 구조 전체 리디자인은 다음 단계.
- 2026년의 실제 이산이 남긴 디지털 자화상의 원본과, 2087년의 기록을 가진 이산은 동일한 경험을 가진 인물이 아니다.
- 도시 대자비는 이산의 복원 신호를 근거로 비인가 기억에 대한 **정리 요청**을 예약한다. 잔상실의 일부 주민은 이를 알고도 방문자에게 위험을 알리지 않았다.
- **대자비에 가는 명확한 목표는 기억 정리 요청을 취소하는 것**이다. 그냥 웹사이트를 떠나면 요청은 미해결로 남고, 브라우저 기록 삭제는 자신이 경험한 인스턴스 전체를 초기화하는 **별개의 선택**이다.
- 사용자는 현실의 다른 사람/브라우저 기록이나 게임 코드를 삭제할 수 없다. 위 도시 기록 정리는 서사 내부의 사건이며 실제 로컬 저장 삭제와 구분한다.

## 첫 플레이 흐름 (10~15분 목표, 미측정)

| 단계 | 필수 조작 | 의도 |
| --- | --- | --- |
| 입장 | 지하 잔상실 탐험, 이산 첫 대화 | 공간과 인물에 애착 형성 |
| 원본 조회 | ABOUT / WRITING / WORKS 3D 단말 중 **2곳** 조사 | 2026년 창작 자료와 2087년 이산 사이의 거리 암시 |
| 임시 복원 | 자화상 장치 조사 → 기억 보관 장치 조사 | 이산을 구함, 동시에 기억 교정 신호 발신 |
| 이상 징후 | 관리인에게 복원 후의 오류 질문 | 탐색할 동기 부여 |
| 기억 탐문 | R-07, 아이, 무전수 **세 명**의 기억 오류 확인 | 서로 다른 맥락의 미심쩍은 단서 |
| 기록 대조 | 중앙 대조 단말에서 **세 기록을 각각 확인** | 플레이어가 직접 일치 시각과 서명 발견 |
| 책임 추궁 | 관리인에게 발신자를 질문 → 이산에게 다시 질문 | 배신은 컴퓨터 문서 대신 인물들이 인정 |
| 선택적 이탈 | 지상으로 가거나 무명사에 남지 않고 떠남 | 강제 영웅화 금지 |
| 지상 | 3D 대자비 시선·엄폐·레이저 통과 | 기억 정리 중단을 위한 목적 있는 잠입 |
| 중앙 기록 | 정리 요청 취소+기억 보존 **또는** 작품 밖에서 내 인스턴스 초기화 | 직접 경험한 관계가 선택의 대가 |

대화는 한 줄씩 보여 주고 다음을 눌러 진행한다. 주요 반전 정보는 한 화면에 쏟아내지 않는다. 불필요한 강제 타이머나 호감도 점수는 없다.

## 중요 버그 수정 / 재현 테스트

**마지막 선택지에서 마우스가 없어지는 문제**
1. `/deleteseoul-lab?debug&fx=off` 접속.
2. 일시정지 → DEBUG → `crossing` 혹은 `decision`으로 이동.
3. 검문소에 도달 후 중앙 단말 마지막 대사를 넘겨 최종 선택 표시.
4. 포인터 잠금이 해제되고 마우스가 나타나며 3D 시점이 움직이지 않는지 확인.
5. '기억 정리 취소'와 '작품 밖에서 내 세계 초기화' 둘 다 클릭 가능한지 확인.
6. 초기화 바깥 화면에서 다시 돌아오거나 실제 v2 저장 키만 삭제되는지 확인.

**서스펜스 단서와 진행**
1. 기존 A/B 퍼즐을 풀지 않고도 지하 장치로 계속 진행 가능한지 확인.
2. 포트폴리오 단말 **2/2**가 되어야 원본 장치가 활성화되는지 확인.
3. 복원 뒤 관리인 대화가 있어야 **3명의 기억 오류** 조사 단계가 시작되는지 확인.
4. NPC의 **3/3** 단서를 본 다음에만 대조 단말이 활성화되는지 확인.
5. 단말에서 **3/3**을 대조하기 전에는 발신자 기록이 나오지 않는지 확인.
6. 단말 조사 뒤 관리인, 그다음 이산 순으로 설명이 풀리는지 확인.
7. 저장→새로고침에서도 진행·기억·대조 상태가 유지되는지 확인.

**레이저, 저장, 공개 원본 회귀**
1. PC/MacBook Air M1과 모바일에서 플레이어 조작 확인.
2. 일시정지·대사·최종 선택 중 대자비의 공격/시선 게이지가 진행되지 않는지 확인.
3. 기록 초기화는 `sanlee-delete-seoul-story-v2` 하나만 삭제하고 기존 `/deleteseoul` 저장 데이터는 훼손하지 않는지 확인.
4. 원래 공개 경로 `/deleteseoul`이 예전처럼 열리는지 확인.
5. `?fx=off`와 기본 FX를 비교하여 평균 FPS·최저 FPS 확인.
6. 타이머가 아니라 실제 첫 플레이로 **10분 이상** 충분히 몰입할 수 있는지 사용자 테스트. 달성하지 못하면 기믹 추가보다 의미 있는 탐색/행동 구간을 검토.
