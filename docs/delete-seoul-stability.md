# DELETE SEOUL 안정화 변경

기준: b477a2ed432d6f84ea58dc1e3109487cc91252e9

## 적용 범위

- 얼굴 복원: 중단된 일시적 장치 상태를 진입/퇴장 때 비우고 저장된 원통·선택에서 재구성한다.
- 空: 마지막 단계 전 계단참의 이동 범위를 제한하고, 최종 목표를 허용 영역 안에 둔다. 실제 이동 없이 완료하지 않는다.
- 게임 시간: 입력 차단과 일시정지를 분리한다. 플레이어·이산·드론·대자비의 시뮬레이션, 대화·복원·결말·쿠키 게임의 예약 작업을 정지/재개한다. 장식용 배경 애니메이션 전체를 정지하는 변경은 아니다.
- 예약 작업: 컴포넌트 해제 때 취소하고, 구역 전환 재요청은 이전 전환을 취소한다. 일시정지 중 나가기의 UI 타이머는 별도로 유지한다.
- 입력: 조이스틱 unmount/포인터 캡처 상실, 점프 버튼 교체, 포커스 상실과 입력 비활성화 때 초기화한다.
- 저장: 버전 없는 백업을 읽고 v1로 저장한다. 슬롯·좌표·횟수를 검증하고 방문 ID를 중복 제거한다. 다른 탭의 삭제를 감지하면 재접속 안내로 전환한다.
- 복귀: 공격 잔여 상태·NPC 경로·전체화면을 정리한다.
- 호환성/접근성: WebGL2 검사, 3D 오류 경계, 게임 팝업의 Tab 포커스 순환과 복귀를 추가한다.
- 성능: 방공호에서 안정적인 FPS를 관찰했다는 이유만으로 성능 모니터가 종료되지 않게 한다. 화질·밝기·난이도 기본값은 유지한다.
- 대사: story.ts의 기존 284·285행 유지. 기존 316행만 합의한 개인 웹사이트 안내로 교체하고 영어도 맞춘다.

## 검증

Node 24에서 `npm test`, `npm run typecheck`, `git diff --check` 실행.
테스트는 저장·타이머·얼굴 런타임·입력·좌표·대자비 프레임 콜백 검증이며 전체 플레이 E2E가 아니다.

`npm run build`는 Google Fonts의 fonts.gstatic.com 파일 다운로드 실패로 완료하지 못했다. 프로덕션 소스의 폰트를 임시 대체해 성공으로 간주하지 않았다.
관리형 미리보기는 Next.js에 `--host ... --strictPort`를 전달해 시작하지 못했다. 실제 브라우저 게임 플레이와 M1 GPU 성능은 미검증이다.

## 병합 전 수동 확인

1. 얼굴 정렬/도시 개입/선택 적용 중 이탈 후 같은 탭 재진입.
2. 空에서 이산보다 먼저 계단참으로 이동한 뒤 마지막 걸음.
3. 조준·발사·사망 복원·쿠키 게임 중 정지/재개 및 다른 탭 전환.
4. 사망 직후 방공호 복귀/작품 퇴장 후 재진입.
5. 터치 이동 유지 중 망원경 진입/종료, 화면 회전, 앱 전환.
6. 다른 탭에서 기록 삭제 후 열린 게임이 이전 기록을 다시 쓰지 않는지.
7. 신규 플레이, 수락 후 재도전, 거부, 삭제 후 재회와 空 전체 진행.

## 이번 변경에 포함하지 않은 항목

M1 실측에 따른 반사/DPR/후처리 조정, 파괴된 엄폐물의 충돌 디자인 변경, 추가 대사/재회 연출 변경, 의존성 패치 업데이트, SEO 확장, GPU/오디오 장기 누수 측정, 대형 컴포넌트의 전면 분리와 CI 구성은 별도 작업이다.
